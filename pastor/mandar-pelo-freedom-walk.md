# Mandar pelo Freedom Walk

Você pede ao Freedom Walk para mandar uma mensagem ou o contato de alguém para outra pessoa, e ele manda depois de você aprovar.

## Quem pode usar
Os pastores gerais e a equipe de apoio que a igreja escolheu. Líder de ministério não usa este recurso. Se um líder precisa que uma mensagem seja enviada, ele fala com um pastor.

## Como fazer
1. No WhatsApp da igreja, escreva o pedido do seu jeito. Exemplo: "Manda para Ana o contato do Paulo, para ela convidar para o grupo."
2. Se houver mais de uma pessoa com o mesmo nome, o Freedom Walk pergunta "Para qual deles?"
3. Ele mostra a prévia: "Vou mandar a Ana exatamente isto: ... Posso enviar?"
4. Toque [Enviar] para mandar, ou [Corrigir] e diga como quer o texto.
5. Ele responde: "Pronto, mandei a Ana."

## Bom saber
- Nada sai sem a prévia e o seu [Enviar].
- Se a conversa da pessoa está fechada, a mensagem fica guardada e sai quando ela escrever.
- Não sai mensagem para menor de idade, para quem pediu para não receber mensagens, nem para número usado por mais de uma pessoa.
- Mensagem para outro pastor segue uma regra própria: só sai se o próprio pastor pedir ou se houver autorização.
- O telefone nunca vai escrito no texto. O contato vai como cartão.
- O envio fica no histórico da conversa.
