# A equipe

Mostra como a equipe está cuidando, para ajudar e não para cobrar.

## Como ver
1. Aba **Você** → **Liderança** → **A equipe**.
2. Use **Todos** ou toque num ministério para filtrar.

<!-- IMAGEM: a tela A equipe com os dois blocos -->

## O que você vê
- **Cada ministério**: quantos pedidos chegaram e quantos foram assumidos.
- **Cada pessoa**, com uma destas etiquetas:
  - **Respondendo**: está atendendo os pedidos.
  - **Vale uma conversa**: tem pedido esperando resposta. Um bom momento para perguntar como ela está.
  - **Sem pedidos**: ainda não chegou pedido para ela.
- Quanto tempo a pessoa leva, em geral, para o primeiro contato.
- Quantas pessoas ela acompanha.

## Bom saber
- Dizer "agora não" nunca é falha. Isso ajuda a igreja a achar outra pessoa.
- Ninguém é comparado com ninguém. Não existe ranking.
- Líder de ministério vê só a equipe do próprio ministério.
