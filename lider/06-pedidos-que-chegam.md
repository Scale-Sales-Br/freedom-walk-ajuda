# Os pedidos que chegam para você

Quando alguém da igreja precisa de você, o Freedom Walk avisa pelo WhatsApp, com botões. É só tocar.

## Os três tipos de aviso
- **Pedido de oração**. Veja [Pedido de oração](07-pedido-de-oracao.md).
- **Pedido para participar do ministério**. Veja [Pedido para participar do ministério](08-pedido-de-ministerio.md).
- **Pedido de cuidado** (conversa, visita, uma pessoa que precisa de alguém).

## Pedido de cuidado
1. O aviso mostra o primeiro nome e o assunto, sem contar a história da pessoa.
2. Toque em [Eu assumo] se você pode cuidar. Quem tocar primeiro fica com o pedido.
3. Depois do toque, você recebe os detalhes para poder cuidar.
4. Se não puder agora, toque em [Não posso agora]. O pedido continua com o resto do time.
5. Enquanto cuida, o botão é [Estou cuidando]. Quando falar com a pessoa, toque em [Já conversei].

## Bom saber
- Dizer que não pode agora nunca é problema. O pedido segue para outra pessoa.
- Quando alguém assume, os outros do time ficam sabendo: "Marcos já assumiu o pedido de Ana."
- O telefone da pessoa só aparece se você pedir o contato. Fica anotado.
- Para parar de receber mensagens, mande SAIR. Atenção: você também deixa de receber os pedidos do seu ministério. Para voltar, mande VOLTAR.
- Se um aviso não abre, mande uma mensagem para o Freedom Walk perguntando.
