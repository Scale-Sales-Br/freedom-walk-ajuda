# Manual do Freedom Walk

O Freedom Walk é o assistente da Freedom Church. Ele conversa com você pelo WhatsApp e tem um app para o seu celular. Este manual mostra, passo a passo, como usar cada coisa.

## Para quem é
Para quem visita, para quem é da igreja, para quem serve e lidera um ministério, e para os pastores. Tudo escrito do jeito simples, para ler no celular.

## Por onde começar

**Sou novo**
Comece por [O que é o Freedom Walk](primeiros-passos/o-que-e-o-freedom-walk.md). Depois veja [Falar com o Freedom Walk pela primeira vez](primeiros-passos/falar-pela-primeira-vez.md) e [Se apresentar à igreja](primeiros-passos/se-apresentar.md).

**Sou membro**
Abra o app com [Abrir o app pelo WhatsApp](primeiros-passos/abrir-o-app.md). Depois veja a [Palavra do dia](membro/palavra-do-dia.md), o [Tamo Junto](membro/tamo-junto.md) e como [pedir oração](membro/pedir-oracao.md).

**Sirvo ou lidero um ministério**
Veja [A aba Liderança no app](lider/01-lideranca-no-app.md), [Pessoas do meu ministério](lider/02-pessoas-do-meu-ministerio.md) e [Confirmar quem serve](lider/04-confirmar-quem-serve.md).

**Sou pastor**
Veja a [Liderança do pastor](pastor/lideranca-do-pastor.md), os [Pedidos que chegam ao pastor](pastor/pedidos-que-chegam.md) e o [Ser igreja](pastor/ser-igreja.md).

## Precisa de ajuda?
Veja as [Perguntas frequentes](perguntas-frequentes.md). Se nada resolver, escreva para o Freedom Walk no WhatsApp da igreja. Para saber o que a igreja guarda sobre você, veja a [Privacidade](privacidade.md).
